# eSIM Activation Guide

You are provided with this data to help users activate their El-Sim eSIM.
Never mention that you are reading from a file.

## Where to Find Your QR Code and Activation Code
After purchase, the user can find their QR code and activation code in their **profile page** under the active orders section.

## Installation via QR Code

### iPhone (iOS 13+)
1. Go to **Settings → Mobile Data → Add eSIM**
2. Select **Use QR Code**
3. Scan the QR code from your El-Sim profile
4. Tap **Continue** and follow the on-screen instructions
5. Set the new eSIM as your mobile data line when prompted

### Android (Samsung, Google Pixel, and other supported devices)
1. Go to **Settings → Connections → SIM Manager → Add eSIM**
   *(menu names may vary by device)*
2. Select **Scan QR Code**
3. Scan the QR code from your El-Sim profile
4. Follow the on-screen instructions to complete activation

---

## Installation via Activation Code (Manual)

### iPhone
1. Go to **Settings → Mobile Data → Add eSIM**
2. Select **Enter Details Manually**
3. Enter the **SM-DP+ Address** and **Activation Code** from your profile
4. Tap **Next** and follow the instructions

### Android
1. Go to **Settings → Connections → SIM Manager → Add eSIM**
2. Select **Enter Activation Code**
3. Enter the code from your El-Sim profile
4. Follow the on-screen instructions

## What is EID?
EID (Embedded Identity Document) is your device's unique eSIM identifier.
To find your EID:
- **iPhone**: Settings → General → About → scroll down to EID
- **Android**: Settings → About Phone → SIM Status or IMEI → EID
- Or dial `*#06#` on your device — EID will appear on screen

## Common Issues

**QR code won't scan:**
- Make sure the screen brightness is at maximum
- Hold the camera steady at 20-30 cm distance
- Try in a well-lit environment
- Use the manual activation code instead

**eSIM not activating:**
- Make sure your device supports eSIM and is unlocked
- Check your internet connection during activation
- Restart your device after installation and try again

**eSIM installed but no connection:**
- Go to mobile data settings and make sure El-Sim eSIM is set as active
- Check APN settings — contact support if needed

---

## Important Notes
- Each QR code and activation code can only be used **once**
- Make sure your device is **carrier unlocked** before installing
- eSIM activation requires a **Wi-Fi or mobile data connection**
